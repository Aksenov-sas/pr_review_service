# Отчет о нагрузочном тестировании микросервиса

## Общая информация

- **Дата тестирования**: 23 ноября 2025
- **Микросервис**: PR Reviewer Assignment Service
- **Цель тестирования**: Проверка производительности и устойчивости сервиса под нагрузкой
- **Инструменты**: k6, Prometheus, Grafana

## Проведенные тесты

### 1. Базовое нагрузочное тестирование (basic.js)
- **Конфигурация**: 5 виртуальных пользователей, 1 минута
- **Основные сценарии**:
  - Создание команд
  - Создание Pull Request'ов
  - Назначение ревьюверов
  - Слияние PR
  - Переназначение ревьюверов

### 2. Тестирование граничных случаев (edge_cases.js)
- **Конфигурация**: 3 виртуальных пользователя, 1 минута
- **Тестовые сценарии**:
  - Создание PR без автора
  - Создание PR с пустым идентификатором
  - Мерж несуществующего PR
  - Переназначение ревьювера у несуществующего PR
  - Переназначение ревьювера у слитого PR

## Результаты тестирования

### Базовое тестирование
- **Процент ошибок**: 33.51% (основная причина - конфликты при создании команд с одинаковыми именами)
- **95-й перцентиль времени ответа**: 8.97ms
- **Успешные операции**:
  - Создание PR: 98%
  - Назначение ревьюверов: 100%
  - Слияние PR: 100%
  - Получение PR для ревьювера: 100%

### Граничные случаи
- **Процент ошибок**: 0% (все проверки прошли успешно)
- **Все граничные случаи обработаны корректно**

- Запросы на переназначение: 141,587 (в основном 404 - несуществующие PR)
- Запросы на получение информации о ревью: 141,432
